Bab 1: 4 Pondasi Berpikir Komputasional (CT)

Logika Solusi Terstruktur

Berpikir Komputasional (Computational Thinking / CT) adalah metode pemecahan masalah yang merumuskan masalah dan solusinya secara terstruktur, sistematis, dan logis sehingga dapat dijalankan oleh manusia maupun komputer. CT bukanlah sekadar belajar coding, melainkan melatih landasan berpikir kritis.

1. Dekomposisi

Memecah masalah kompleks yang besar menjadi bagian-bagian kecil yang lebih sederhana dan mudah dikelola.

💡 Analogi: Memecah perakitan sepeda menjadi komponen roda, rantai, stang, dan rem.

2. Pengenalan Pola

Mencari kesamaan, tren, atau pola berulang di dalam masalah untuk mempermudah penyelesaian.

💡 Analogi: Mengenali pola cuaca mendung dan angin kencang sebagai tanda akan turun hujan.

3. Abstraksi

Fokus hanya pada informasi penting dan relevan, serta mengabaikan detail rumit yang tidak dibutuhkan.

💡 Analogi: Peta rute MRT hanya fokus pada nama stasiun, tanpa lekukan jalan raya asli.

4. Desain Algoritma

Menyusun instruksi atau langkah-langkah sistematis berurutan dari awal hingga akhir untuk menyelesaikan masalah.

💡 Analogi: Resep langkah-langkah memasak mi instan dari merebus air hingga disajikan.

🔒 Pemecahan Kunci Gembok Kombinasi

Petunjuk Logika Kode 3-Digit:

  • (682): Satu angka benar & posisinya tepat
  • (614): Satu angka benar tapi posisinya salah
  • (206): Dua angka benar tapi posisinya salah semua
  • (738): Tidak ada angka yang benar
Kunci: 042

🧩 Dekomposisi: Membagi menjadi 3 posisi digit: [D1] [D2] [D3].

🔍 Pola & Abstraksi: Petunjuk D mengeliminasi (7,3,8). Petunjuk A & B membuktikan 6 salah. Petunjuk A menyisakan 2 di Digit 3 [ _ ] [ _ ] [ 2 ].

📐 Algoritma: Dari (206), angka 0 benar di Digit 1 [ 0 ] [ _ ] [ 2 ]. Dari (614), 4 benar di Digit 2. Solusi akhir = 042.

📍 Path: (0,0) ➔ Maju 2x ➔ (2,0) ➔ Belok Kiri ➔ Maju (2,1) ➔ Belok Kanan ➔ Maju (3,1) ➔ Belok Kiri ➔ Maju 2x ➔ Finish (3,3).

🎯 Abstraksi: Abaikan warna lantai/mesin, hanya fokus koordinat X,Y.

📐 Langkah Algoritma: 1. Start(0,0) -> 2. Maju (2,0) -> 3. Kiri ke (2,1) -> 4. Kanan ke (3,1) -> 5. Kiri ke (3,3).

🔢 Analisis Pola Deret Angka

Barisan: 2, 5, 10, 17, 26, ? (Suku 6), ? (Suku 7)

Selisih: +3, +5, +7, +9 ➔ Selisih berikutnya (+11, +13). Rumus $n^2+1$.
Hasil: 37 & 50

Suku ke-7 = 37 + 13 = 50 (atau $7^2 + 1 = 50$).

Bab 2: Memahami Pengertian Struktur Data

Manajemen Memori RAM

Struktur Data adalah metode atau cara khusus untuk mengatur, mengorganisasi, menyimpan, dan mengelompokkan data di dalam memori komputer (RAM) sehingga data dapat diakses, dimanipulasi, dan diproses secara efisien oleh algoritma.

Analogi Perpustakaan Sekolah

Jika ribuan buku dicampurkan begitu saja dalam satu tumpukan raksasa di lantai (tanpa struktur data), Anda membutuhkan waktu berjam-jam untuk mencari satu buku sejarah. Namun, jika buku disusun pada rak bertingkat bernomor (Kategori Sejarah, Rak A, Indeks 2), buku dapat ditemukan dalam hitungan detik. Rak berstruktur itulah gambaran dari Struktur Data.

Klasifikasi Utama

1. Struktur Data Linear:

Data tersusun secara berurutan satu demi satu dalam satu baris memori. (Array, Stack, Queue, Linked List).

2. Struktur Data Non-Linear:

Data terhubung secara hierarki atau jaringan/grafik. (Tree/Pohon, Graph).

Bab 3: Jenis-Jenis Struktur Data Linear

Array, Stack & Queue
Indexed Access

3.1 Array (Larik)

Kumpulan elemen data bertipe sama yang disimpan berurutan pada lokasi memori berdampingan. Akses langsung menggunakan Indeks (mulai 0).

👞 Analogi: Deretan loker sepatu bernomor urut di sekolah (Loker 0, Loker 1, Loker 2, dst).
Index: [0] [1] [2] [3] [4]
Nilai: [75, 88, 92, 60, 85]
LIFO (Last-In First-Out)

3.2 Stack (Tumpukan)

Elemen yang terakhir masuk (Push) akan menjadi elemen pertama yang keluar (Pop).

📚 Analogi: Tumpukan piring di kantin atau fitur "Undo" pada editor teks.

Push(10) ➔ Push(25) ➔ Push(40)

Pop() ➔ Angka 40 keluar pertama!

FIFO (First-In First-Out)

3.3 Queue (Antrean)

Elemen yang pertama masuk (Enqueue) akan menjadi elemen pertama yang keluar (Dequeue).

🎟️ Analogi: Antrean pembelian tiket bioskop atau antrean pencetakan dokumen di printer.

Enqueue("Andi") ➔ Enqueue("Budi")

Dequeue() ➔ "Andi" keluar pertama!

Bab 4: Algoritma Pencarian (Search Algorithm)

Linear vs Binary Search

4.1 Linear Search (Pencarian Berurutan)

Kompleksitas: O(n)

Memeriksa setiap elemen data satu per satu secara berurutan dari indeks 0 hingga akhir. Sangat fleksibel untuk data acak (belum terurut).

Target: 15 pada Array [8, 3, 25, 15, 42]
➔ Cek [0]: 8 (Salah)
➔ Cek [1]: 3 (Salah)
➔ Cek [2]: 25 (Salah)
➔ Cek [3]: 15 (BENAR! Ditemukan di langkah 4).

4.2 Binary Search (Pencarian Biner)

Kompleksitas: O(log n)

Mengambil titik tengah (MID) dan membelah dua wilayah pencarian. Syarat Mutlak: Data HARUS sudah terurut secara ascending!

Target: 42 pada Array Terurut [5, 12, 18, 24, 31, 42, 55, 68, 70]
➔ Mid: 31 (42 > 31 ➔ Buang setengah kiri)
➔ Mid: 55 (42 < 55 ➔ Buang setengah kanan)
➔ Mid: 42 (BENAR! Ditemukan dalam 3 langkah super cepat).

Bab 5: Algoritma Pengurutan (5 Sort Algorithms)

Ascending & Descending

Berikut adalah prinsip 5 algoritma pengurutan utama untuk menyusun data acak [5, 2, 8, 1, 3] menjadi terurut naik (Ascending):

5.1 Insertion Sort (Sisipan)

Menyisipkan elemen satu per satu ke posisi yang sesuai pada bagian array yang sudah terurut.

[5 | 2, 8, 1, 3] ➔ Sisip 2 ➔ [2, 5 | 8, 1, 3] ➔ Sisip 1 ➔ [1, 2, 5, 8 | 3] ➔ [1, 2, 3, 5, 8]

5.2 Selection Sort (Pilihan)

Mencari nilai terkecil pada bagian belum terurut, lalu menukarnya (Swap) ke posisi paling depan.

Min=1 (Tukar 1 & 5) ➔ [1, 2, 8, 5, 3] ➔ Min=3 (Tukar 3 & 8) ➔ [1, 2, 3, 5, 8]

5.3 Bubble Sort (Gelembung)

Membandingkan 2 angka berdampingan dan menukarnya jika urutannya salah, hingga angka terbesar mengapung ke kanan.

Pass 1: Tukar (5,2) & (8,1) & (8,3) ➔ [2, 5, 1, 3, 8]
Pass 2 & 3 ➔ Hasil: [1, 2, 3, 5, 8]

5.4 Quick Sort (Cepat)

Memilih elemen Pivot, membagi array menjadi dua kelompok (< Pivot dan > Pivot), lalu mengurutkan secara rekursif.

Pivot=3 ➔ Kiri[2,1] + Pivot[3] + Kanan[5,8] ➔ Gabung ➔ [1, 2, 3, 5, 8]

5.5 Merge Sort (Pengurutan Gabung)

Prinsip Divide and Conquer: Membelah array menjadi sub-array tunggal, lalu menggabungkan kembali (Merge) secara terurut.

Divide: [5,2,8,1,3] ➔ [5,2] [8] [1,3] ➔ [5] [2] [8] [1] [3]
Merge: [2,5] + [8] ➔ [2,5,8] & [1,3] ➔ Final Merge ➔ [1, 2, 3, 5, 8]

Bab 6: Ringkasan Perbandingan Algoritma

Matriks Performa
Algoritma Prinsip Utama Kelebihan Kekurangan Kasus Terbaik
Linear Search Cek elemen satu per satu dari awal. Sederhana, cocok data acak. Lambat pada data besar O(n). Pencarian data sedikit / tak terurut.
Binary Search Bagi dua area pencarian (MID). Sangat cepat O(log n). Wajib data terurut. Pencarian database / kamus besar.
Insertion Sort Sisip elemen ke posisi tepat. Efisien untuk data hampir rapi. Lambat jika acak total O(n²). Data ukuran kecil & kontinu.
Selection Sort Cari minimum, tukar ke depan. Jumlah swap sedikit. Selalu cek seluruh sisa. Memori yang membatasi operasi swap.
Bubble Sort Tukar pasangan berdampingan. Paling mudah dipahami. Performa paling lambat. Edukasi dasar konsep sorting pemula.
Quick Sort Partisi berdasarkan elemen Pivot. Sangat cepat di praktik nyata. Sensitif pemilihan pivot. Pemrosesan umum data skala besar.
Merge Sort Belah hingga tunggal, gabung terurut. Performa konsisten stabil O(n log n). Butuh memori ekstra. Pengurutan data raksasa / linked list.
