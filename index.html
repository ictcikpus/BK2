Bab 1: 4 Pondasi Berpikir Komputasional (Computational Thinking)

Berpikir Komputasional (CT) adalah metode pemecahan masalah yang merumuskan masalah dan solusinya secara terstruktur, sistematis, dan logis sehingga dapat dijalankan oleh manusia maupun komputer.

1.1 Pengertian 4 Pondasi Utama CT

🧩 Dekomposisi (Decomposition)

Memecah masalah kompleks yang besar menjadi bagian-bagian kecil yang lebih sederhana dan mudah dikelola.

Analogi: Memecah perakitan sepeda menjadi komponen roda, rantai, stang, dan rem.

🔍 Pengenalan Pola (Pattern Recognition)

Mencari kesamaan, tren, atau pola berulang di dalam masalah untuk mempermudah penyelesaian berdasarkan pengalaman terdahulu.

Analogi: Mengenali pola cuaca mendung dan angin kencang sebagai tanda akan turun hujan.

🎯 Abstraksi (Abstraction)

Fokus hanya pada informasi penting dan relevan, serta mengabaikan detail rumit yang tidak dibutuhkan.

Analogi: Melihat peta rute busway hanya fokus pada nama halte, tanpa memperhatikan lekukan jalan raya asli.

📐 Desain Algoritma (Algorithm Design)

Menyusun instruksi atau langkah-langkah sistematis berurutan dari awal hingga akhir untuk menyelesaikan masalah.

Analogi: Resep langkah-langkah memasak mi instan dari merebus air hingga disajikan.

1.2 Bahan Latihan & Kasus Dunia Nyata

Kasus 1: Pemecahan Kunci Gembok Kombinasi

Petunjuk Logika: (682: 1 angka benar & posisi tepat), (614: 1 angka benar tapi posisi salah), (206: 2 angka benar tapi posisi salah), (738: Tidak ada angka benar).

• 🧩 Dekomposisi: Membagi menjadi 3 digit [_][_][_].

• 🔍 Pengenalan Pola: Eliminasi 7, 3, 8, dan 6.

• 🎯 Abstraksi: Abaikan merk & bahan gembok.

• 📐 Hasil Akhir Kombinasi: 042.

Kasus 2: Robot Navigasi Petak 4x4

Robot harus berjalan dari Start (0,0) menuju Finish (3,3) menghindari dinding di (1,1) dan (2,2).

1. Start (0,0) -> Maju ke (2,0)

2. Belok Kiri -> Maju ke (2,1)

3. Belok Kanan -> Maju ke (3,1)

4. Belok Kiri -> Maju 2 langkah ke Finish (3,3)

Kasus 3: Outfit Matching (Kemeja & Celana)

3 Kemeja (Putih, Biru, Merah) dan 2 Celana (Hitam, Cokelat).

• Pola Kombinasi: 3 Kemeja × 2 Celana = 6 Varian Pasangan Outfit.

Kasus 4: Deret Angka & Selisih Pertambahan

Barisan: 2, 5, 10, 17, 26, ...

• Selisih: +3, +5, +7, +9 (Bilangan Ganjil / $n^2+1$)

• Suku ke-6: $26 + 11 = $ 37

• Suku ke-7: $37 + 13 = $ 50

Bab 2: Memahami Pengertian Struktur Data

Struktur Data adalah metode khusus untuk mengatur, mengorganisasi, menyimpan, dan mengelompokkan data di dalam memori komputer (RAM) agar dapat diakses & diproses secara efisien.

Analogi Dunia Nyata: Rak Perpustakaan Sekolah

Jika ribuan buku dicampurkan begitu saja dalam satu tumpukan raksasa di lantai (tanpa struktur), Anda akan membutuhkan waktu berjam-jam untuk menemukan satu buku sejarah.
Namun jika buku dikelompokkan pada rak-rak bernomor berdasarkan kategori (Kategori Sejarah, Rak A, Tingkat 2), Anda dapat menemukan buku tersebut dalam hitungan detik.

1. Struktur Data Linear

Elemen-elemen data tersusun secara berurutan satu demi satu dalam satu baris memori. Contoh: Array, Stack, Queue, Linked List.

2. Struktur Data Non-Linear

Elemen-elemen data terhubung secara hierarki atau berjejaring, tidak dalam satu baris lurus. Contoh: Tree (Pohon), Graph (Jaringan).

Bab 3: Jenis-Jenis Struktur Data Linear

3.1 Array (Larik)

Kumpulan elemen bertipe sama pada lokasi memori berdampingan. Akses data langsung menggunakan Indeks (mulai dari 0).

Analogi: Deretan loker sepatu bernomor urut (0, 1, 2, dst).

3.2 Stack (Tumpukan)

Bekerja berdasarkan prinsip LIFO (Last In, First Out) — data terakhir masuk adalah yang pertama keluar.

Operasi: Push (Tambah ke TOP), Pop (Ambil dari TOP).

3.3 Queue (Antrean)

Bekerja berdasarkan prinsip FIFO (First In, First Out) — data pertama masuk adalah yang pertama keluar.

Operasi: Enqueue (Masuk dari Rear), Dequeue (Keluar dari Front).

Bab 4: Algoritma Pencarian (Search Algorithm)

4.1 Linear Search (Pencarian Berurutan)

Memeriksa setiap elemen data satu per satu dari awal (indeks 0) hingga akhir. Cocok untuk data acak / tidak terurut.

Kompleksitas Waktu: O(n)

4.2 Binary Search (Pencarian Biner)

Mengambil titik tengah (MID) dan membelah dua area pencarian. Syarat Mutlak: Data HARUS sudah terurut!

Kompleksitas Waktu: O(log n)

Bab 5: Algoritma Pengurutan (Sort Algorithm)

Simulasi pengurutan angka terkecil ke terbesar (Ascending) untuk data acak: [5, 2, 8, 1, 3].

5.1 Insertion Sort (Pengurutan Sisipan)

Menyisipkan data satu per satu ke posisi yang sesuai pada bagian yang sudah terurut.

Proses: [5 | 2, 8, 1, 3] ➔ [2, 5 | 8, 1, 3] ➔ [2, 5, 8 | 1, 3] ➔ [1, 2, 5, 8 | 3] ➔ [1, 2, 3, 5, 8]

5.2 Selection Sort (Pengurutan Pilihan)

Mencari angka terkecil pada bagian belum terurut, lalu menukarnya (swap) ke depan.

Proses: Cari min (1) tukar dgn 5 ➔ [1, 2, 8, 5, 3] ➔ Cari min (3) tukar dgn 8 ➔ [1, 2, 3, 5, 8]

5.3 Bubble Sort (Pengurutan Gelembung)

Membandingkan dua pasangan berdampingan dan menukarnya jika urutannya salah, hingga angka terbesar mengapung ke kanan.

Pass 1: [5,2,8,1,3] ➔ [2,5,1,3,8] | Pass 2: [2,1,3,5,8] | Pass 3: [1,2,3,5,8]

5.4 Quick Sort (Pengurutan Cepat)

Memilih elemen Pivot, membagi array menjadi dua kelompok (< Pivot di kiri, > Pivot di kanan), lalu memproses secara rekursif.

Pivot = 3 ➔ Kiri [2,1] + [3] + Kanan [5,8] ➔ Gabung: [1,2,3,5,8]

5.5 Merge Sort (Pengurutan Gabung)

Membelah (Divide) array hingga tunggal, lalu menggabungkan kembali (Merge) sambil mengurutkan.

Divide: [5,2,8,1,3] ➔ [5,2,8] & [1,3] ➔ Merge & Sort: [1,2,3,5,8]

Bab 6: Ringkasan Perbandingan Algoritma

Algoritma Prinsip Utama Kelebihan Kekurangan Kasus Terbaik
Linear Search Cek elemen satu per satu Sederhana, data acak Lambat data besar Data sedikit
Binary Search Bagi dua area pencarian Sangat cepat Wajib terurut Kamus / Database terurut
Insertion Sort Sisip ke posisi tepat Efisien data hampir rapi Lambat jika acak total Data kecil / kontinu
Selection Sort Cari minimum, tukar ke depan Jumlah swap sedikit Selalu cek seluruh sisa Memori terbatasi swap
Bubble Sort Tukar pasangan berdampingan Mudah dipahami Performa paling lambat Edukasi pemula
Quick Sort Partisi berdasarkan Pivot Sangat cepat di praktik Sensitif pilihan pivot Pemrosesan umum data besar
Merge Sort Belah hingga tunggal, gabung Performa stabil konsisten Butuh memori ekstra Data raksasa
